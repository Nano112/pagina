# pagina

Renders an "article folder" (markdown + assets + Kineglyph scene modules) into a static docs site.

Workspaces:
- `packages/core` — environment-agnostic parsing/rendering (`@pagina/core`)
- `packages/shell-static` — static site shell (planned)
- `packages/vite` — Vite integration (planned)
- `packages/cli` — CLI (planned)
